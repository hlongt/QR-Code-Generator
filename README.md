# 二维码生成器 · QR Code Generator

一个**单文件、纯前端**的二维码生成器。打开 `二维码生成器.html` 就能用：输入内容即时生成二维码，自定配色、码点形状和中心图标，一键导出 PNG 或 SVG。

所有渲染都在你自己的浏览器里完成，输入的内容不会被上传到任何服务器。

---

## 快速开始

1. 双击 `二维码生成器.html`，用 Chrome / Edge / Firefox / Safari 打开；
2. 左侧第一行选择内容类型（文本 / 网址 / Wi-Fi），在下方输入内容；
3. 二维码会随输入实时刷新，右侧「实时预览」所见即所得；
4. 需要图片时点「下载 PNG 图片」，需要矢量稿时点「下载 SVG」。

> 首次打开需要联网加载一个二维码渲染库（见「技术实现」），之后只要页面不刷新就完全离线可用。

## 功能一览

### 1. 三种内容类型

| 类型 | 输入项 | 默认示例 | 编码内容 |
| --- | --- | --- | --- |
| 文本 | 单行输入 | `例如 你好 Hello!` | 原样文本 |
| 网址 | 链接 | `例如 https://hlongt.github.io` | URL 字符串 |
| Wi-Fi | 网络名称、密码、加密方式 | 空 | `WIFI:S:名称;T:加密;P:密码;;` |

- 文本框与网址框为**空值 + 浅色示例提示**；输入框为空时，预览会用示例内容生成一张**可正常扫描**的示范二维码（示例本身不含「例如」二字），此时预览脚注会标注「示例」。
- Wi-Fi 类型未填写「网络名称」时不会生成无意义的空码，预览区显示「尚未输入内容」占位。
- 三种类型的内容输入框高度统一，切换类型时不会跳动。

### 2. 外观自定义

| 项目 | 可选项 |
| --- | --- |
| 码点颜色 | 任意取色，或直接输入十六进制色值 |
| 背景色 | 任意取色；可勾选「透明」输出透明底 PNG |
| 码点形状 | 方块 / 圆点 / 圆角（默认）/ 平滑 / 典雅 |
| 定位角外框 | 直角 / 圆角（默认）/ 圆形 |
| 定位角内点 | 圆点（默认）/ 方块 |

### 3. 中心图标（Logo）

- 「上传图片」选择本地图片（`image/*`，PNG / JPG / SVG 等），实时嵌入二维码中心；
- 「图标大小」10%–50% 占比，「图标边距」0–20，用来在图标与码点之间留出安全距离；
- 未上传图标时，这两个滑杆会自动淡出并禁用，避免误调；
- 「移除」可一键去掉图标。

### 4. 输出规格

| 项目 | 可选项 |
| --- | --- |
| 像素尺寸 | 300 / **500（默认）** / 1000 / 2000 px（正方形） |
| 纠错等级 | L 7% / M 15% / Q 25% / **H 30%（默认）** |

「像素尺寸」对 PNG 生效：导出时会按所选尺寸**重新渲染**，而不是把预览图拉伸放大，所以 2000px 的成品依然边缘锐利。

### 5. 导出与复制

- **下载 PNG 图片** —— 按所选像素尺寸重新渲染后下载，文件名形如 `QR_Code_1729920000000.png`；
- **下载 SVG** —— 矢量文件，可无损放大用于印刷，文件名形如 `QR_Code_Vector_1729920000000.svg`；
- **复制图片** —— 直接把二维码以 PNG 写入剪贴板，可粘贴到聊天窗口或文档中。

### 6. 历史记录

- 右上角「历史记录」打开右侧抽屉，列出最近 **10 条**记录（相同内容自动去重、新的在前）；
- 点击任一记录可恢复该条内容与类型；
- 「清空记录」删除全部记录；按 `Esc` 关闭抽屉；
- 记录保存在浏览器 `localStorage`（键名 `qr_history`），只存在本机，不上传。

## 技术实现

- **单文件**：HTML + CSS + JavaScript 全部内联，无需安装、无需构建、无依赖打包；样式为手写 CSS（暖纸色 + 细线分隔 + 等宽小标签的编辑排版风格），图标为内联 SVG。
- **渲染引擎**：[qr-code-styling 1.5.0](https://github.com/qr-code-styling/qr-code-styling)，通过 jsDelivr CDN 引入；页面内以 SVG 形式渲染，可随容器等比缩放。
- **中文编码修复**：该库内置的 `qrcode-generator` 默认按 `charCodeAt & 0xff` 单字节取码，含中文时会被截断成乱码。本页在渲染前先用 `TextEncoder` 把内容编码成 UTF-8 字节串再交给库，因此中文、英文、数字、符号混排都能被正常识别。
- **主题**：仅浅色纸感主题，无暗色模式，无第三方 UI 框架。

## 浏览器兼容

支持所有现代浏览器（Chrome / Edge / Firefox / Safari，含移动端）。用到的主要特性：`CSS Grid`、`color-mix()`、`Intl` 本地时间、`Clipboard API`。

「复制图片」依赖浏览器的剪贴板图片写入能力（Chrome / Edge / Safari 较新版本均支持）；若浏览器不支持，可改用下载 PNG。

## 使用建议

- **嵌了 Logo 就用 H 级纠错**（30%），码点被图标遮挡的部分仍能被识别；
- **印刷**请导出 2000px 的 PNG 或直接使用 SVG，并保证成品实际打印边长不小于 2 cm；
- **对比度**：码点与背景要有足够反差，浅色码点配浅色背景、或反色（浅码深底）容易扫不出；
- **留白**：二维码四周尽量保留一点空白（静区），不要紧贴其他图形或文字；
- 扫不出来时，先检查对比度、Logo 是否过大（建议 ≤ 40%），再把纠错等级提高一级试试。
